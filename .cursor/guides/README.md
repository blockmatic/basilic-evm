# Cursor Guides

Human-facing documentation for working with Cursor and AI-assisted development in this codebase. These guides provide process documentation and workflow references for developers using Cursor.

## Quick Reference

| Guide | Purpose | When to Use |
|-------|---------|-------------|
| [quick-start.md](./quick-start.md) | 5-minute reference card with essential patterns | First time using Cursor, quick lookup |
| [cursor-flow.md](./cursor-flow.md) | Complete workflow covering full development lifecycle | Deep dive into workflows, comprehensive reference |
| [extensions.md](./extensions.md) | VS Code/Cursor extensions and their roles | Setting up extensions, understanding tool integration |

## Learning Path

**New to Cursor?** Start here:

1. **Quick Start** → Read [`quick-start.md`](./quick-start.md) for essential patterns (5 min)
2. **Full Workflow** → Read [`cursor-flow.md`](./cursor-flow.md) for complete development lifecycle
3. **Tool Setup** → Read [`extensions.md`](./extensions.md) when setting up your environment

**Experienced user?** Jump directly to:
- [`cursor-flow.md`](./cursor-flow.md) - Complete reference with all phases, commands, and best practices
- [`extensions.md`](./extensions.md) - Extension configuration and usage

## Guide Descriptions

### [quick-start.md](./quick-start.md)
Minimal reference card with essential AI-assisted development patterns. Provides quick access to core principles and links to detailed sections in `cursor-flow.md`.

### [cursor-flow.md](./cursor-flow.md)
Comprehensive workflow documentation covering:
- Discovery & Research (Phase 0)
- Architectural Planning (Phase 1)
- Implementation Planning (Phase 2)

- Review & Refinement (Phase 4)

Includes model selection frameworks, decision trees, command references, and best practices. This is the authoritative source for all workflow details.

### [extensions.md](./extensions.md)
Documentation for VS Code/Cursor extensions used in this project, including:
- CodeRabbit (AI code review)
- Biome (formatting and linting)
- Tailwind CSS IntelliSense
- Mermaid diagram support
- GitHub Actions workflow support
